# Vazir font

The bundled `Vazir-Variable-v30.1.0.woff2` is the original, unmodified Vazir
variable font from the author's official v30.1.0 release. The upstream project
was subsequently renamed Vazirmatn; this asset retains the Vazir design/name.

- Author: The Vazir Project Authors, led by Saber Rastikerdar.
- Release: https://github.com/rastikerdar/vazirmatn/releases/tag/v30.1.0
- Source: https://raw.githubusercontent.com/rastikerdar/vazirmatn/v30.1.0/dist/Vazir-Variable.woff2
- License: SIL Open Font License 1.1, reproduced in `Vazir-OFL.txt`.
- SHA-256: `3d7c6820aa45e4f1c569561a7dabc6472153e14ea883b5b6ef41aa764c66def0`
- Size: 41,696 bytes.

The application serves this file locally. Its CSS Unicode range applies Vazir
only to Persian/Arabic script and joining controls, preserving the existing
Latin UI font and monospace fonts in code blocks. `font-display: swap` keeps
content visible while the local font loads.
