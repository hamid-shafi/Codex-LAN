# The product

**[Workspace](workspace/)** is Codex LAN: one trusted host, independent teammates,
and a shared browser workspace. Its server, workers, and browser interface live
together under `workspace/codex_lan/`; their installed paths remain unchanged.

**[Desktop](desktop/)** is the optional, earlier GTK application. Its Python UI,
assets, and launch scripts are kept together, separate from the shared workspace.

Start with the [product overview](../docs/product/OVERVIEW.md), or follow
[host setup](../docs/operations/SETUP.md) to share the workspace with your team.
